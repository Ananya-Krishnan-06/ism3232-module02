# ISM3232 - Module 2: zsh Navigation and File Operations
## Commands Practiced
| Command        | What it does                      |
|----------------|-----------------------------------|
| pwd            | Prints working directory          |
| ls             | Lists visible files and folders   |
| ls -la         | Lists all files even hidden ones  |
| cd             | Change directory to required file |
| mkdir          | Makes a directory for a new file  |
| touch          | Create a new file or update       |
| echo           | Prints text or writes into a file |
| cat            | Displays full contents of a file  |
| head           | Displays lines upto first 10      |
| cp             | Copies files or directories       |
| mv             | Moves files or renames them       |
| rm             | Delete files or directories       |
| tree           | Tree like structure of files      |
| code           | Launches VS Code from terminal    |
|----------------|-----------------------------------|

## Week 3: Virtual Environments and .zshrc
| Command        | What it does                               |
|----------------|--------------------------------------------|
| -m venv        | creates seperate environment for python    |
| pip            | installing, upgrading and managing python  |
| cat            | contents of file are displayed to terminal |
| .zshrc         | Configuring aliases for the zsh shell      |
| alias          | creates a shortcut for a longer command    |
| ll             | alias for ls -la = list all files          |
| c              | alias for clear to clear text              |
| py             | alias for python3 to run interpreter       |
| gs             | alias for git status for current directory |
| ga             | alias for git add = stages files for commit|
| gcmsg          | alias to create a git commit with message  |
| gp             | alias to upload git branch                 |
| gl             | alias to display git commit history        |
| tree2          | alias to display folder hierarchy          |
| mkcd           | new directory and change to single step    |
| source         | execute commands from specific file        |
| deactivate     | exits current python environment           |
|----------------|--------------------------------------------|
